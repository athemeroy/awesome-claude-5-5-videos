# X 预览 MP4 的文件属性

这些是本次检索及引用来源回溯取得的**附件文件属性**，包括对照片、教程、录屏与转载；不能当作 Opus 原创电影的总体分布。X 返回的文件往往是低清预览，而非作者的最高画质母版。

- 取得并完成 Hypit 探测／九帧抽样：**1180 个 MP4 附件**。
- 附件时长中位数：**40.1 秒**；最短 3.6 秒，最长 2869.6 秒。时长只描述取得的文件，不证明 Opus 独立生成了同样长的影片。
- 文件含音轨：**969 个**；无音轨：211 个。“含音轨”只说明容器有音频流，不说明语音／音乐内容或听感。
- 例如 [@jake11moran 的 27 秒片](https://x.com/jake11moran/status/2103237884564414633)按提示词要求无配乐，X 文件仍带 AAC 流；用 ffmpeg 测得全段均值约 -79.5 dB、最大约 -61.4 dB，几乎是静音。不能把上面的“有音轨”数量解释成“有可听声音”。
- 最常见的可取预览分辨率为 **480×270**（647 个附件）。不能据此评判上传母版。
