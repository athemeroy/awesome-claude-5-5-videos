# Copyable video production brief

Copy this template into a project and replace the brackets; write “N/A” where a field does not apply. Update estimates with actual usage after production. Naming Opus as a contributor does not identify the tool that rendered the frames.

```markdown
# [Working title] — production brief

## Goal and delivery
- Audience and one thing they should understand or feel: [ ]
- Where it will appear; duration; aspect ratio; resolution; frame rate; language: [ ]
- Acceptance owner and deadline: [ ]
- Deliverables: [MP4, editable project, render command, subtitles/audio, asset and cost log]
- Must remain exact (product claims, names, logo, text, identity, facts): [ ]

## Inputs and rights
| Asset, data, or reference | File/URL and version | Owner, license, permitted use | How it enters the film |
|---|---|---|---|
| [ ] | [ ] | [ ] | [ ] |
- Missing assets, rights, or facts that require a human decision: [ ]

## Who does what
- Opus 5.5: [planning / storyboard / rendering code / tool calls / review; record actual work]
- Frame source: [Canvas/SVG/WebGL/Three.js/Blender/Manim/Remotion, existing footage, or image/video model + version; specify each shot]
- Audio and captions: [recording / TTS / music / sound tools, source and version]
- Human work and approvals: [brief, asset preparation, shot selection, revisions, final review]

## Shots and visible states
| Shot and time | Start state | Visible action/change | End state | Exact text, fact, or asset |
|---|---|---|---|---|
| [01, 00:00–00:00] | [ ] | [ ] | [ ] | [ ] |
| [02, 00:00–00:00] | [ ] | [ ] | [ ] | [ ] |
- Continuity rules (character, product, camera, lighting, timing, loop seam): [ ]

## Acceptance gates — record result and reviewer at each gate
1. **Storyboard and keyframes:** [required frames/states, text and asset checks]; result/reviewer: [ ]
2. **Hardest 2–4 second sample:** [adjacent frames, occlusion/contact, motion, seek-order repeatability or baked simulation, audio/caption sync]; result/reviewer: [ ]
3. **Whole film:** [watch and listen throughout; duration, frame rate, resolution, exact text, sound levels, sync, rights, reproducible render]; result/reviewer: [ ]

## Factual or physical claims (N/A for a purely illustrative effect)
- Claim and intended public wording: [ ]
- Checkable reference: [source data/formula, version, units, boundary conditions, license]
- Test and tolerance; independent reviewer/result: [ ]
- If unchecked, label the result as an illustration, not a validated simulation: [ ]

## Actual work, cost, and disclosure
- Model calls and usage: [attempts, input/output/cache usage, actual bill or labeled estimate]
- Other services, assets, and compute: [tool/version, attempts, bill or estimate, render time]
- Human work: [who changed what, revision count, review time]; elapsed start-to-accepted time: [ ]
- Failed renders and remaining defects: [ ]; unverified claims or unavailable evidence: [ ]
- Public credit: [what Opus did, what rendered pixels/audio, supplied material, human contribution]
```
