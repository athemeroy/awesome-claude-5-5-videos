# 新作品透露了哪些制作方式

[首页](../README.zh-CN.md) · [完整目录](library.zh-CN.md) · [English](workflow-analysis.md)

新帖子给出了几种有用的制作方式。但这些例子不能得出 Opus、Sonnet、Haiku 与疑似 Fable 的通用排名。本页依据作者披露、三个补读线程与预览取样。[来源账本](../data/claude55-source-review-2026-10-10-followup.csv) · [取样覆盖与作者分布](collection-analysis.zh-CN.md)。

## 输入不同，任务也不同

| 案例 | 作者披露的输入 | Claude 的制作角色 | 可复用的经验 |
|---|---|---|---|
| [参考驱动的混合媒体片](https://x.com/notdwd/status/2107816799840690589) | skill 与[详细公开任务](https://x.com/notdwd/status/2107817421981843679)：侧脸、手部视频、Pexels 默认素材、歌曲、纸张纹理与逐帧时间。 | 作者称 Fable 将明确设计制作成混合媒体短片。 | 简短的触发请求背后，可以有准备好的素材和精确制作系统。 |
| [半条毯子的故事](https://x.com/Vallabh469/status/2108494077389926611) | 人类设计的概念、叙事与角色设定。 | 作者称 Opus 负责构图、动画与声音。 | 故事和角色设计应归于提供这些输入的人。 |
| [北京宣传片](https://x.com/shengtang135754/status/2108549555528872041) | 要求寻找素材视频、使用 MiniMax 旁白的任务说明。 | Haiku 选择、组织视频、文字和旁白。 | “Haiku 做视频”也可以是剪辑流程，不代表逐像素代码绘图。 |
| [声音与运动可视化](https://x.com/aicreataro/status/2108091976574988390) | MiniMax H3 人物、Midjourney 主视觉、MiniMax 音乐。 | Opus 配合 Blender／Python 制作深度、粒子与镜头变化。 | 生成素材与代码特效是不同环节。 |

这是有意选择的四条案例，不是输入类型的总体分布。相似画风不能说明使用了相同工具。复用公开提示时，要保留它所要求的输入。

## 一条提示，也可以有很多轮修改

[F1 进站帖](https://x.com/rubenssoto_ai/status/2108289170871582851)称只给一条人类提示。但[作者回复](https://x.com/rubenssoto_ai/status/2108608936295408050)说明，Opus 多次拒绝中间结果。作者认为这增加了用量和耗时。他还[对程序化音频表示不确定](https://x.com/rubenssoto_ai/status/2108608684876071241)。

其他作者明确记录了人类工作：[Taxtello 是第五版，并有批评 agent](https://x.com/daniel_haida/status/2108595684236755242)；[游戏开发者提供购买素材，用了约二十条提示和两天](https://x.com/Rush3rx/status/2108607656776876368)；[Understory 花费数天，并有人类指导](https://x.com/DannyLimanseta/status/2107505970809336071)。

应分别记录人类提示次数、内部工具与审查轮次、达到接受标准的时间。帖子没有统一披露这三项。因此，“一次生成”不是可直接比较的制作工作量单位。

## 每 token 便宜，不等于整项任务同比例便宜

下表是精选作者报告的任务费用。账单未独立核实，也不是受控测试。这里只比较作者记录的总额，不引入 API 单价判断。

| 作者的对照 | 报告费用 | 根据费用计算的比例 | 比较范围 |
|---|---:|---:|---|
| [金门桥](https://x.com/Solomonrojie/status/2108322280094728219)：Haiku／Opus | $2.19／$3.04 | Haiku 为 Opus 的 72.0%，少 28.0%。 | 相同场景任务；作者指出结果细节不同。 |
| [毛茸茸螃蟹](https://x.com/vib3coded/status/2108190478889824662)：Sonnet／Opus | $11.25／$13.30 | Sonnet 为 Opus 的 84.6%，少 15.4%。 | 相同提示；没有共同验收评分或独立账单。 |
| [F1 进站团队](https://x.com/rubenssoto_ai/status/2108289170871582851)：Haiku 执行端／整个 Claude 团队 | $61.77／$96.27 | 执行端占团队报告费用的 64.2%。 | Opus 负责规划与审查；这是团队，不是 Haiku 单独完成。 |

F1 作者记录执行端使用 819.9M／914.7M token，占 89.6%，并说明存在反复审查。评估流程费用时，除了单价，还要看用量与修改循环。这些数据仍不能解释账单的每一项收费。

不要把这几笔美元费用平均成模型排名。任务、素材、思考强度、工具和验收标准都不同。[费用记录指南](visual-effects-fit.zh-CN.md)说明应记录什么。

## Haiku 承担多种角色，反馈也不一致

目录已包含作者报告的 Haiku 动效、诗歌、SVG、场景对照、素材剪辑与执行端案例。在取样的[三十点零五九秒动效片](https://x.com/badboyfoxy/status/2108089492016103775)中，可以看到文字、缓动曲线、轨道图形与光条。[北京案例](https://x.com/shengtang135754/status/2108549555528872041)则要求素材视频与外部旁白。这是不同任务。

反向案例也要保留：[EnvolDev 在夜间列车任务上更喜欢 Luna](https://x.com/EnvolDev/status/2107973447230091623)，而[SVG 鹈鹕作者更喜欢 Haiku](https://x.com/xueyu1125/status/2108082476975554587)。后者的 Haiku 用 OpenCode，Luna 用 Codex，执行工具也不同。这些报告可以支持尝试某类任务，不能支持“Haiku 总是更好”或通用质量分数。

## 动画像真的，不代表讲解已经验证

[Sonnet 建楼作者](https://x.com/Solvaix/status/2107548992640880755)明确说建造顺序是编排的、几何经过简化，也没有工程计算。取样可见楼体升高和吊车变化。取得的录屏约二十九点一一八秒，原帖描述六十八秒时间线。录屏片长与场景时间线要分别记录。

[进球重建](https://x.com/lv_feng47448/status/2108397996740432136)报告使用位置数据、球体模拟与动作捕捉。公开输入有助于理解流程，但不能独立证明物理重建正确。同样，做出数学或科学讲解动画，也不能证明讲解中的主张。

复用时，先确定交付物：示意动画、交互场景录屏、素材剪辑，还是经过验证的讲解。再保留相应原始资料、渲染工具和可检查条件。[制作指南](visual-effects-fit.zh-CN.md)提供逐任务检查，[路径图文](production-resources.zh-CN.md)给出实际案例。
