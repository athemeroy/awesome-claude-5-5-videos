## Reusable open-source production systems

| Preview and project | What can be reused and what the preview shows |
|---|---|
| <a href="https://lemomo-ai.github.io/lemo-opuscar/"><img src="../assets/resource-thumbnails/lemo-opuscar.webp" width="210" alt="Lemo-Opuscar official cover showing a collage of film styles"></a><br>[Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) · [original post](https://x.com/lemomo_ai/status/2103811634565415152) | The current [gallery has 43 styles](https://lemomo-ai.github.io/lemo-opuscar/), each with sample films and `STYLE.md` links; the older cover remains a preview. [OPUSCAR 98](https://lemomo-ai.github.io/lemo-opuscar/opuscar98/#styles) is one compilation honoring 98 Best Picture winners, with style notes, frames, reusable prompts and shot direction for each tribute. These are different sets of entries. The [director guide](https://github.com/lemomo-ai/lemo-opuscar/blob/main/DIRECTOR.md), [technique guide](https://github.com/lemomo-ai/lemo-opuscar/blob/main/TECHNIQUE.md), and [sample scene code](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/crayon-book/demo/film.js) make the brief, storyboard, deterministic frame rendering, shared timing, and sound checks inspectable. The creator says Canvas/WebGL code draws the films without a video-generation model; the repository alone cannot audit every model call or finished film. The [root license checked at this revision](https://github.com/lemomo-ai/lemo-opuscar/blob/e3cb16f63768c68693ff0e15171d6e755457cc32/LICENSE) is MIT; third-party assets retain their own terms. |
| <a href="https://github.com/francozanardi/papermotion#first-snow-snow"><img src="../assets/resource-thumbnails/papermotion.webp" width="210" alt="Snowy paper-cut scene from Papermotion's Opus 5.5 snow film"></a><br>[Papermotion](https://github.com/francozanardi/papermotion) | A reusable paper-cut animation engine with deterministic physics, character rigs, offline rendering, frame grabs, contact sheets, and sound checks. The still comes from its *snow* film, which the README labels Opus 5.5. The README also labels *demo*, *rooftops*, and *sea* Opus 5.5; *light* and *embers* are labeled GPT 6 Astra. Read each sample's model label separately. |
| <a href="https://x.com/servasyy/status/2104039075175182487"><img src="../assets/new-case-thumbnails/2104039075175182487.webp" width="210" alt="Character animation by a creator using ClaudeAnimationBase"></a><br>[ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase) · [creator example](https://x.com/servasyy/status/2104039075175182487) | A public p5.js and p5.brush animation starter with character expressions, storyboard and contact-sheet steps, and a render workflow. The preview shows @servasyy's personal-story film made with this base; the public starter is reusable input, not the exact source for every shot in the finished film. |
| <a href="https://x.com/makevoid/status/2103869704955900023"><img src="../assets/new-case-thumbnails/2103869704955900023.webp" width="210" alt="Motion-graphics music-video preview by makevoid"></a><br>[Motion Graphics Music Video skill](https://github.com/makevoid/motion-graphics-music-video-skill) · [creator example](https://x.com/makevoid/status/2103869704955900023) | A Claude Code plugin and Ruby toolkit for planning and assembling music-video motion graphics from a supplied song and brief. Its p5.js workflow can call external Fal image, video, and audio models; the preview is a multi-tool creator example, not evidence that Opus supplied all moving pixels. |

All four resources sit outside the September 26 frozen corpus and do **not** increase the 1,401-file or 168-case counts. ## Where to start

| Your task | A useful starting file | October 11 review |
|---|---|---|
| Choose a look for your story | [Lemo-Opuscar style index](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/README.md) and [production skill](https://github.com/lemomo-ai/lemo-opuscar/tree/main/plugin/skills/lemo-opuscar) | The plugin separates shared guides from each film project. Supply the story, audio assets and preference for storyboard review. |
| Build a scene with paper physics | [Papermotion workflow](https://github.com/francozanardi/papermotion#how-it-works) | The author recommends extending the template's scene primitives. Fixed steps and seeded randomness support repeatable frame rendering. |
| Animate a recurring drawn character | [ClaudeAnimationBase animation guide](https://github.com/JohnHeibel/ClaudeAnimationBase/blob/main/ANIMATION_GUIDE.md) | Characters, shot timing and the renderer are separate. The author notes that watercolor fills can render slowly without a dedicated GPU. |
| Make an MV around a supplied song | [Motion Graphics Music Video quick start](https://github.com/makevoid/motion-graphics-music-video-skill#quick-start) | The plugin combines a song, characters and external generation tools. Record Fal generation spending separately from Claude usage. |
