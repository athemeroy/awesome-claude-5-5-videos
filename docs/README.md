## Two dated datasets

**The current collection** merges dated source ledgers into [collection-index.csv](../data/collection-index.csv). Its unit is a source post, including replies and comparisons. [Collection analysis](collection-analysis.md) tracks model mentions and preview sampling.

**The September 26 file study** uses [domain-style.csv](../data/domain-style.csv), [cases.csv](../data/cases.csv) and the [frozen snapshot](../data/corpus-snapshot.json). Content, style, duration and color results retain their original sample and dates. Later source posts do not silently become classified files in that study.
